## Sample 1: How to Create a GitHub Repository (Mobile App)

1. Open the GitHub app and sign in.
2. Tap the **+** icon at the top right.
3. Tap **New repository**.
4. Enter a repository name.
5. Choose **Public** or **Private**.
6. Turn on **Add a README**.
7. Tap **Create repository**.

**Tip:** Use a short, clear name so others can find your project easily.

## Sample 2: How to Edit a README

1. Open your repository.
2. Tap **EDIT** next to `README.md`.
3. Make your changes.
4. Tap the check icon, then **COMMIT**.

## Sample 3: FAQ

**Q: What is a README?**
A: A README is the first file people read in a project. It explains what the project is and how to use it.

**Q: What is a commit?**
A: A commit saves your changes to the repository with a short message.
